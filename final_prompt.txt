### Safari CSS Bugs (Two Critical Issues)

**Bug #1: Absolute Positioning on `::-webkit-calendar-picker-indicator` Pseudo-Element**
- Location: Approximately lines 95-109 in styles.css
- Root cause: Safari cannot handle absolute positioning on pseudo-elements
- Impact: Calendar icon misaligned or invisible in Safari browser
- Fix: Remove `position: absolute`, `right`, `top`, `transform`, `width`, `height` properties while preserving custom background
- Expected outcome: Browser uses native indicator positioning

**Bug #2: `display: none` in Safari-Specific Media Query**
- Location: Approximately lines 113-119 in styles.css
- Media query pattern: `@media not all and (min-resolution:.001dpcm)` (Safari detection)
- Root cause: Media query completely hides calendar picker in Safari
- Impact: Safari users cannot open date picker; date filtering unavailable
- Fix: Completely remove entire Safari-specific media query block
- Expected outcome: Calendar picker remains visible and functional
