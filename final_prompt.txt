### Two Critical CSS Bugs to Fix

**Bug #1: `position: absolute` on `::-webkit-calendar-picker-indicator` pseudo-element**
- Location: Approximately lines 95-109 in `src/static/css/styles.css`
- Root cause: Safari cannot properly handle absolute positioning on pseudo-elements
- Impact: Calendar icon is misaligned or completely invisible in Safari
- Fix approach: Remove `position: absolute`, `right`, `top`, `transform`, `width`, `height` properties while preserving custom background styling
- Expected result: Browser uses native indicator positioning

**Bug #2: `display: none` in Safari-specific media query**
- Location: Approximately lines 113-119 in `src/static/css/styles.css`
- Media query pattern: `@media not all and (min-resolution:.001dpcm)` (Safari detection)
- Root cause: Media query completely hides the calendar picker trigger element in Safari
- Impact: Safari users cannot open date picker; date filtering functionality broken
- Fix approach: Completely remove the entire Safari-specific media query block
- Expected result: Calendar picker remains visible and functional
