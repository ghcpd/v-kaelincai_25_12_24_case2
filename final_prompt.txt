## Inputs & Context

### Problem Statement

**Application:** E-commerce order filtering web application with date picker functionality
**Technology Stack:** Flask (Python backend), HTML/CSS/JavaScript frontend  
**Issue:** Date picker is completely broken in Safari browser; works normally in Chrome and Firefox

### Critical CSS Bugs to Fix

**Bug #1: `position: absolute` on `::-webkit-calendar-picker-indicator`**
- Location: Approximately lines 95-109 in `src/static/css/styles.css`
- Root cause: Safari cannot properly handle absolute positioning on pseudo-elements
- Impact: Calendar icon misaligned or invisible; users cannot see date picker functionality
- Fix: Remove `position: absolute`, `right`, `top`, `transform`, `width`, and `height` properties from this selector

**Bug #2: `display: none` in Safari-specific media query**
- Location: Approximately lines 113-119 in `src/static/css/styles.css`  
- Root cause: Safari-detection media query `@media not all and (min-resolution:.001dpcm)` completely hides the calendar picker
- Impact: Safari users cannot open the date picker; date filtering functionality unavailable
- Fix: Remove entire Safari-specific media query block (including opening `@media` and closing brace)
