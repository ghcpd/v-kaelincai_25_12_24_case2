## Inputs & Context

### The Problem: Safari Date Picker CSS Incompatibility

**Issue Summary:**
- The order filtering web application has a date picker that works in Chrome and Firefox
- **Safari browser**: Date picker is completely broken and non-functional
- Root cause: CSS file contains two critical bugs that affect Safari's WebKit engine

**Bug #1: `position: absolute` on `::-webkit-calendar-picker-indicator` pseudo-element**
- Location: Lines ~95-109 in `src/static/css/styles.css`
- Impact: Safari cannot handle absolute positioning on this pseudo-element
- Result: Calendar icon is misaligned or invisible; users cannot see they can select dates

**Bug #2: `display: none` in Safari-specific media query**
- Location: Lines ~113-119 in `src/static/css/styles.css`
- Media query: `@media not all and (min-resolution:.001dpcm)` (Safari-specific)
- Impact: Completely hides the calendar picker trigger in Safari
- Result: Safari users cannot click to open the date picker; cannot use date filtering
